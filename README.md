# 🐦 Flappy Bird Game

A desktop version of the classic Flappy Bird game developed in **C#** using **Windows Forms** and **Visual Studio 2022**.

## 🎮 Features

- Classic Flappy Bird gameplay
- Collision detection
- Score tracking
- Keyboard controls
- Endless obstacle generation
- Game Over and Restart functionality
- Custom game graphics

## 🛠 Technologies Used

- C#
- Windows Forms
- Visual Studio 2022
- .NET Framework

## 🚀 How to Run

1. Clone or download this repository.
2. Open `flappy bird game.sln` in Visual Studio 2022.
3. Build the solution.
4. Run the project.

## 📚 Programming Concepts

- Event-Driven Programming
- Object-Oriented Programming
- Timers
- Collision Detection
- Game Loop
- Keyboard Event Handling
- PictureBox Controls
